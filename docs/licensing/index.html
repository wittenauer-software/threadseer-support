Edition guide

Plans & Licensing

Threadseer is designed around a useful Community workflow and a Microsoft-managed Professional edition for larger and more advanced analysis.

Professional is not publicly purchasable. No Marketplace submission has been made. The planned United States launch price is US$20 per assigned user per month or US$200 per assigned user per year, but checkout, assignment, and availability instructions will be published only after a future live offer is verified.

How Professional licensing is designed to work

  1. When a public offer is available, customers purchase the Professional plan through Microsoft Marketplace.
  2. An administrator assigns the license to users through Microsoft's licensing tools.
  3. The Power BI host reports the assigned Threadseer service-plan state to the visual through Microsoft's licensing API.
  4. An Active or Warning plan enables Professional. Other, unavailable, or unsupported states remain Community.

Threadseer does not run a publisher licensing server, create customer accounts, or transmit report/process data as part of licensing. Professional features require an applicable Professional license for users accessing those features. License assignment and entitlement are managed through Microsoft's licensing tools.

Microsoft documents AppSource purchase and Microsoft 365 license assignment for licensed visuals. See Microsoft's licensing and transactability guidance.

Professional environment limitations

Microsoft currently documents license management or enforcement as unsupported in:

  • Publish to web and PaaS embedded scenarios;
  • national or regional clouds where transactability is unavailable;
  • Power BI Report Server; and
  • REST API PDF or PowerPoint export.

Threadseer does not treat an unsupported or unavailable license signal as Professional access. Community behavior may remain available where the visual itself can run, but that does not promise that every environment supports interactive analysis, rendering, export, or Marketplace distribution. Review Microsoft's current Power BI visual licensing limitations.

Pricing and availability

  • Community is free for personal, educational, evaluation, and internal commercial use. It is not limited to non-commercial use.
  • Professional launch pricing is US$20 per assigned user per month or US$200 per assigned user per year.
  • There is no time-limited Professional trial at launch; Community is the permanent free evaluation path.
  • Initial Marketplace availability is limited to the United States.

Community is a feature tier of the same proprietary Threadseer visual, not a separate open-source or redistributable product. When Threadseer is acquired through Microsoft Marketplace, Community use is governed by the Microsoft Standard Contract.

These are approved launch terms, not a claim that checkout is live. When Threadseer becomes publicly available, this page will identify the exact Marketplace offer, purchase path, assignment guidance, and effective plan terms. Watch Release Notes for verified availability.
