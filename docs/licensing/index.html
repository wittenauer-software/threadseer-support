Pricing and availability

  • Community is free for personal, educational, evaluation, and internal commercial use.
  • Professional launch pricing is US$20 per assigned user per month or US$200 per assigned user per year.
  • There is no time-limited Professional trial at launch. You can use Community free for as long as you like.
  • The initial Marketplace plan is limited to the United States.

Community is a feature tier of the same proprietary Threadseer visual, not a separate open-source or redistributable product. When Threadseer is acquired through Microsoft Marketplace, Community use is governed by the Microsoft Standard Contract.

When a live offer is verified, this page will link to the Marketplace listing and provide purchase and license-assignment instructions. Until then, check Release Status for confirmed availability.

For Power BI administrators: how Professional licensing works
  1. Customers purchase Professional through Microsoft Marketplace after the offer becomes available.
  2. An administrator assigns the Professional plan using Microsoft's licensing tools.
  3. Power BI tells Threadseer whether the current user has an assigned Professional plan. Threadseer does not receive or retain the underlying Microsoft plan identifier.
  4. If Power BI cannot confirm Professional access, Threadseer continues with Community limits.

Threadseer does not operate a separate licensing server, create customer accounts, or send report or process data as part of licensing. Microsoft manages purchasing, assignment, and license status. See Microsoft's licensing guidance.

Power BI environments with Professional licensing limits

Microsoft currently does not support licensed custom-visual plans in every Power BI environment. Professional licensing is unsupported in:

  • Publish to web and PaaS embedded scenarios;
  • national or regional clouds where Marketplace purchasing is unavailable;
  • Power BI Report Server; and
  • REST API PDF or PowerPoint export.

Community may still work where the visual itself is supported, but this does not guarantee interactive analysis, rendering, export, or Marketplace availability in every environment. Review Microsoft's current Power BI visual licensing limitations.
