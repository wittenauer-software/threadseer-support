Support

Start with the Getting Started guide, then use the public issue tracker for reproducible product defects, documentation problems, accessibility problems, and feature requests.

Keep operational data private. Do not upload employer event logs, report files, screenshots with case identifiers, tenant details, credentials, or proprietary field names. Build a synthetic reproduction instead.

Before opening an issue

  1. Confirm Case ID, Activity, and Timestamp are mapped to the intended columns.
  2. Check that timestamps have a consistent data type and valid values.
  3. Press Analyze or Reanalyze after changing the mapped data or filters.
  4. Try the same steps in a blank report with a small synthetic dataset.
  5. Review the known issues and product limits.

Include in a bug report

  • Threadseer version from the PBIVIZ filename or, after public release, the Marketplace/version details supplied with the visual. Threadseer does not currently expose an in-visual About page.
  • Power BI Desktop, Service, or embedded environment and its version.
  • Exact reproduction steps using synthetic field names and data.
  • Expected and actual result.
  • Whether the problem also occurs in a blank report.
Report a bugRequest a feature

A GitHub account is required, and you must sign in before opening an issue. Browsing existing issues remains public. If you received a private Professional Preview and cannot use GitHub, reply to the pilot invitation instead.

Security reports

Use private vulnerability reporting. Do not disclose a suspected vulnerability publicly.

Private account, legal, or privacy questions

Do not place personal, account, purchase, licensing, or privacy-rights information in a public issue, and do not use the security-report channel for ordinary support. A verified private support/privacy contact and Marketplace-specific contact path will be published before public sale. If you receive Threadseer through Microsoft before then, use the private publisher contact supplied with that distribution.

Support is provided on a reasonable-efforts basis. No response or resolution time is guaranteed unless a separate written agreement says otherwise.
