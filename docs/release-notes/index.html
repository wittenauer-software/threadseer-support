Release Notes

Verified public changes to Threadseer will be recorded here by version and release date.

No Marketplace submission has been made. Threadseer 0.1.0.105 is a local pre-submission validation build, not a public Marketplace release, and there is no verified download or purchase link to publish.

0.1.x validation series

Public release date: Not released · Last reviewed: August 21, 2026

Available in the current pre-submission build

  • Explicit Analyze and Reanalyze snapshot lifecycle.
  • Process discovery across Process Map, Variants, Compare, Conformance, Drivers, Bottlenecks, Rework, Improve, Cases, and Data Quality.
  • Conformance Analysis using Accepted observed paths, one explicit Primary path, exact full-sequence scoring, deviation explanations, and case and Driver Analysis handoffs.
  • A consolidated Conformance process map with a compact path selector, six summary cards, deviation overlay switch, and route legend. Colors share the main-map meaning for primary flow, shortcuts, repetition, and activity categories while using distinct green, magenta, and amber encodings for accepted-only, unexpected, and deviation evidence.
  • The Conformance map now shares the Process Map's visible zoom, zoom-out, and Fit controls plus mouse-wheel zoom, drag-pan, and keyboard movement. Compact graph geometry and route-attached deviation badges keep the unified view readable.
  • The checked-in Power BI sample opens Conformance with the dominant path Primary and Medical Review accepted, making the Primary-versus-Accepted distinction immediately visible.
  • Power BI Desktop validation fixes for Conformance pagination and sample-canvas height so all expected paths, deviation rows, and investigation actions remain reachable.
  • Driver Analysis for transparent investigation of where queue wait, processing time, or rework is concentrated, with case-level traceability and explicit association-not-causation guidance.
  • Side-by-side variant comparison plus bounded workflow-regularity, resource/handoff, and shortcut evidence in Compare and Improve.
  • Case-level traceability, Power BI interactions, quality disclosure, cancellation, and stale-snapshot handling.
  • Community and Professional edition policy with Microsoft-host licensing integration.
  • Empty external network privileges and no publisher-operated process telemetry.
  • Pre-analysis warnings for blank or unreadable required Timestamp values and unreadable optional End Timestamp values, before the user deliberately analyzes the selection.
  • Aggregate Data Quality guidance when unusually granular Activity labels are likely to make the process map harder to interpret; Threadseer never merges or rewrites customer labels automatically.

Public availability

Threadseer has not been submitted to Microsoft Marketplace. The reserved offer name is Threadseer; the planned initial market is the United States; Community is free; and the planned Professional launch price is US$20 per assigned user per month or US$200 per assigned user per year. There is no time-limited Professional trial planned at launch because Community is the permanent free evaluation path. Public installation, purchasing, assignment, version, and Marketplace-link details will be published here only after a future submission, approval, and go-live are verified. Power BI certification is deferred until after Marketplace launch.
