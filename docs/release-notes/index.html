Release status

This page separates internal validation from a version that customers can install through Microsoft Marketplace.

No Marketplace submission has been made. Threadseer 0.1.0.116 is a local pre-submission validation build, not a public Marketplace release. There is no verified public download, purchase link, or installation path.

Current validation focus

Version 0.1.0.116 makes process-map transitions keyboard-focusable on the same element that responds to Enter and Space. It also prepares a deterministic portrait layout for every page in the sample report. It retains the 0.1.0.115 Power BI Value-field formatting and the 0.1.0.114 dashboard safeguard that prevents a larger read-only tile from loading indefinitely when it receives only part of its filtered selection.

The exact 0.1.0.116 package, sample report, Power BI Desktop analysis, four portrait report layouts, prepared Marketplace media, and Power BI Service report are reconciled. In Chrome and Edge, the exact report retained all 12,200 test events, restored 1,880 cases and 10 variants, exposed all ten analytical views, and passed transition selection with both Enter and Space. Edge also retained the analyzed state at 200% and 400% browser zoom. Firefox was owner-attested against the exact 0.1.0.116 report. Broader Microsoft-host permutations remain historical evidence until repeated against the final candidate. Actual Power BI Mobile app validation remains pending.

What remains before a public release

  • Select the immutable submission candidate and repeat the remaining exact-candidate accessibility, offline, mobile, Microsoft-host permutations, and any changed Marketplace-media checks.
  • Complete the remaining exact-candidate cross-platform and Microsoft licensing checks.
  • Keep the published support and privacy mailbox monitored, and confirm the Partner Center contact path.
  • Submit the exact candidate to Microsoft and confirm approval and public availability before publishing installation or purchase links.

After launch

Each public release entry will identify the exact version and release date, then summarize:

  • New: customer-facing capabilities.
  • Improved: changes that make existing workflows clearer or more reliable.
  • Fixed: resolved customer problems.
  • Known limitations: boundaries that may affect use.

Detailed engineering validation remains in the private product repository. This page and the public GitHub tracker provide the customer-facing history.
