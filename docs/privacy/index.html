Privacy Notice

Your process data stays in Power BI. Threadseer does not send it to Wittenauer Software or store a copy on services we operate.

This Privacy Notice explains how information is handled by the Threadseer Power BI visual, this support website, and the associated GitHub support resources. Threadseer is published and owned by Wittenauer Software LLC.

Privacy at a glance

Inside Power BI

Threadseer analyzes the report data Power BI provides to the visual. It has no external network permission and does not send that data to us.

On this website

This is a static GitHub Pages site. Wittenauer Software does not run advertising, tracking pixels, user profiling, contact forms, or website analytics here.

On GitHub

Bug reports and feature requests are public. GitHub processes information under its own policies, so use synthetic examples and do not post sensitive information.

Your data inside Power BI

Threadseer operates inside the Microsoft Power BI custom visual environment. Power BI provides the visual with the report data needed to perform the analysis and display the results. Depending on your report, that data may include:

  • event data;
  • activity names;
  • timestamps;
  • case identifiers;
  • measures;
  • field names; and
  • other values selected by the report author.

Threadseer processes this information inside Power BI and does not transmit it to Wittenauer Software or services we operate.

Threadseer:

  • does not declare external network privileges;
  • does not transmit customer event data to Wittenauer Software;
  • does not transmit field names, report names, case identifiers, or process metrics to Wittenauer Software;
  • does not use Wittenauer Software analytics or telemetry to collect report contents or process data; and
  • does not require a Threadseer account to perform analysis within the visual.

Analysis is initiated through user interaction with the visual, including the Analyze and Reanalyze workflows.

Information generated as part of that analysis remains within the Power BI environment unless a user uses functionality provided by Power BI or another application to export, copy, save, or otherwise share it.

Microsoft services

Power BI, Microsoft Fabric, Microsoft Marketplace, and the environments in which Threadseer runs are Microsoft products and services.

Microsoft may process information in connection with those services independently of Threadseer.

Your organization's Microsoft configuration, security policies, data residency settings, retention policies, and applicable Microsoft agreements govern Microsoft's processing of that information.

Threadseer does not control Microsoft's collection, storage, or processing of information through Microsoft services.

This support website

The Threadseer support website is a static website hosted using GitHub Pages.

Threadseer does not operate:

  • advertising;
  • behavioral analytics;
  • tracking pixels;
  • user profiling;
  • contact forms; or
  • publisher-operated website analytics.

GitHub may process technical information associated with hosting and delivering GitHub Pages, such as request, device, network, account, or diagnostic information, according to GitHub's own policies.

Public GitHub support

Threadseer uses GitHub for public bug reports, feature requests, documentation feedback, general product questions, and support discussions. Anything you submit through a public GitHub issue is public.

Do not submit:

  • customer or employer datasets;
  • event logs containing confidential information;
  • Power BI report files containing sensitive information;
  • screenshots containing confidential information;
  • personal information;
  • credentials or authentication information;
  • confidential tenant or environment information;
  • proprietary information you are not authorized to disclose; or
  • any other information that should not be public.

Whenever possible, use synthetic, anonymized, or non-confidential examples when reporting an issue.

Information submitted through GitHub is processed by GitHub according to GitHub's applicable terms and privacy policies.

Private security reports

Do not disclose a suspected security vulnerability through a public GitHub issue. Use the Threadseer project's private vulnerability reporting process.

Do not include customer datasets or other confidential information unless it is strictly necessary to describe the security issue and you are authorized to disclose that information.

What Wittenauer Software stores

Because Threadseer does not send report or process data to Wittenauer Software, we do not maintain a server-side copy of it. We cannot retrieve, inspect, modify, export, or delete data contained within your Power BI reports.

Information voluntarily submitted through GitHub is retained and managed through GitHub according to GitHub's services, policies, and the actions available to users through GitHub.

Requests concerning information submitted to GitHub should use the account and repository controls GitHub makes available. We cannot retrieve or delete report data that Threadseer never sent to us.

Children's privacy

Threadseer is a business analytics tool and is not designed or directed specifically toward children.

Threadseer does not use user accounts or systems operated by Wittenauer Software to intentionally collect personal information from children through the Power BI visual.

Changes to this notice

We may update this Privacy Notice when Threadseer, this support website, applicable requirements, or our practices change.

Material changes will be published on this page with an updated effective date.

Previous versions may remain available through the public repository's commit history.

Questions and support

For non-confidential general questions about Threadseer, this Privacy Notice, documentation, or product behavior, use the Threadseer GitHub support repository.

Do not include personal, account, purchase, privacy-rights, confidential, customer, or employer information in public GitHub issues. Email Wittenauer Software LLC at jasonwittenauer@wittenauersoftware.com for private account, purchase, licensing, legal, or privacy-rights questions. Do not email Power BI report files, event logs, credentials, tenant or customer data, or proprietary field names.

Potential security vulnerabilities should be reported through the project's private vulnerability reporting process rather than through a public issue.

Private vulnerability reporting is only for suspected security issues; it is not a general privacy or customer-support mailbox.
