Known issues and product limits

Confirmed defects and intentional operating limits are tracked separately so you can tell a reproducible bug from a documented boundary.

Version scope: Threadseer 0.1.0.107 pre-submission build · Last reviewed: August 21, 2026

Known issues

The public GitHub tracker is the source of truth for confirmed current defects. Reports carrying the known issue label have been accepted as reproducible product issues; an empty result means no open issue currently carries that label.

Product limits

  • Community supports up to 25,000 input events per explicit analysis.
  • Professional has a measured 100,000-event baseline. Adaptive Scale may attempt larger complete selections when local Power BI resources permit, up to an absolute 1,000,000-event ceiling.
  • Capacity above the Professional baseline is not guaranteed and varies with data shape, memory, Power BI, WebView2, and device resources.
  • Threadseer never mines an incomplete prefix after resource admission or the Power BI host stops loading data.
  • The process map applies density limits to keep the workspace usable; narrow report filters when activity or transition cardinality is extreme.
  • The Cases view projects at most 200 matching cases, and a selected case timeline projects at most 500 events.
  • Changed fields or Power BI filters can make the current snapshot stale. The prior snapshot remains visible until you deliberately Analyze the new selection.

Supported Power BI environments

The current pre-submission build is validated locally in Power BI Desktop and the packaged host. Power BI service validation remains a separate external gate. The exact Threadseer version and Microsoft host-version requirements for a public release will be recorded in Release Notes. Embedded, national or regional cloud, Report Server, and export scenarios have additional licensing or host limits and must not be assumed equivalent.

Licensing limits

Professional is not publicly available and no Marketplace submission has been made. Microsoft licensing is unsupported in several embedded, national/regional cloud, Report Server, and REST export environments. See Plans & Licensing for the current boundary.

Before reporting a problem

Follow the support checklist and reproduce the behavior with synthetic data. Do not attach operational, confidential, or personal data to a public issue.
