Product limits

Data size

  • Community supports up to 25,000 event rows in each analysis.
  • Professional has a supported baseline of 100,000 event rows.
  • Professional may attempt complete datasets above 100,000 rows, up to 1,000,000, when Power BI and device resources permit. Larger analyses are not guaranteed.
  • If Power BI cannot load the full filtered dataset, Threadseer stops instead of analyzing partial data.
  • A read-only dashboard tile may receive only the first 10,000 events from a larger selection. Threadseer keeps Analyze disabled and directs you to the source report instead of loading indefinitely or analyzing incomplete tile data.

Process map

Very large numbers of activities or connections can make a process map difficult to read. Threadseer applies display limits to keep the workspace usable. Narrow the Power BI filters when the map is too dense.

Case details

The Cases view displays up to 200 matching cases at a time. A selected case timeline displays up to 500 events. Use search or another view to narrow a large group.

Filters and refreshed results

Changing a mapped field or Power BI filter marks the current results as needing a refresh. Threadseer keeps the previous results visible until you deliberately choose Analyze new selection.

Supported Power BI environments

The current 0.1.0.116 pre-submission build has been validated in Power BI Desktop, the packaged test environment, and Chrome and Edge Power BI Service, including all four deterministic portrait report layouts. The exact Service report retained all 12,200 test events, restored 1,880 cases and 10 variants, exposed all ten analytical views, and passed transition selection with Enter and Space. Edge also retained the analyzed state at 200% and 400% browser zoom. Firefox was owner-attested against the exact 0.1.0.116 report. Broader Microsoft-host permutations remain historical evidence until repeated against the final candidate. Read-only dashboard tiles stop safely instead of loading indefinitely when Power BI supplies only the first 10,000 events. Actual Power BI Mobile app validation remains pending. The exact Threadseer and Power BI versions supported at public launch will be listed in Release Status.

Embedded reports, national or regional clouds, Power BI Report Server, and export features have additional Power BI or licensing limits. Do not assume they behave the same as Power BI Desktop or Service.

Licensing limits

Professional is not publicly available, and Threadseer has not been submitted to Microsoft Marketplace. Microsoft does not support licensed custom-visual plans in every Power BI environment. See Plans & Pricing for the current list.

Before reporting a problem

Try the quick troubleshooting steps and reproduce the behavior with synthetic data. GitHub issues are public, so do not attach operational, customer, confidential, account, or personal information.
