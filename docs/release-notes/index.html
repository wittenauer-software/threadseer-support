Release status

This page separates internal validation from a version that customers can install through Microsoft Marketplace.

No Marketplace submission has been made. Threadseer 1.0.0.0 is a local pre-submission validation build, not a public Marketplace release. There is no verified public download, purchase link, or installation path.

Current validation focus

Version 1.0.0.0 replaces the leading-zero 0.1.0.116 package after Partner Center rejected that version format. The product behavior is unchanged: it keeps the keyboard-focusable process-map transitions, deterministic portrait layouts, Power BI Value-field formatting, and the dashboard safeguard that prevents a larger read-only tile from loading indefinitely when it receives incomplete data.

The exact 1.0.0.0 package and sample report are reconciled and directly analyzed in Power BI Desktop across all ten analytical views. The 0.1.0.116 packaged-test, portrait-layout, Chrome and Edge Service, Edge zoom, and owner-attested Firefox results remain historical evidence for the unchanged runtime rather than being relabeled as 1.0.0.0. Exact 1.0.0.0 Service repetition, broader Microsoft-host permutations, and actual Power BI Mobile app validation remain pending.

What remains before a public release

  • Select the immutable submission candidate and repeat the remaining exact-candidate accessibility, offline, mobile, Microsoft-host permutations, and any changed Marketplace-media checks.
  • Complete the remaining exact-candidate cross-platform and Microsoft licensing checks.
  • Keep the published support and privacy mailbox monitored, and confirm the Partner Center contact path.
  • Submit the exact candidate to Microsoft and confirm approval and public availability before publishing installation or purchase links.

After launch

Each public release entry will identify the exact version and release date, then summarize:

  • New: customer-facing capabilities.
  • Improved: changes that make existing workflows clearer or more reliable.
  • Fixed: resolved customer problems.
  • Known limitations: boundaries that may affect use.

Detailed engineering validation remains in the private product repository. This page and the public GitHub tracker provide the customer-facing history.
